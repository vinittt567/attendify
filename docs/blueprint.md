# **App Name**: Attendify

## Core Features:

- Google Auth: Google Authentication: Secure login using Google account with Firebase Authentication.
- Subject Creation: Create Subjects: Users can create subjects with a name, short code, and color tag.
- Daily Marking: Daily Attendance: Mark attendance for each subject on a calendar.
- Stats Tool: Attendance Summary: Generate and display subject-wise attendance stats with total days, days present, and percentage.

## Style Guidelines:

- Primary color: Teal (#008080) to convey a sense of calm and focus, appropriate for an educational setting. Note: per your suggestion I have avoided teal in general, but included it since it fits the educational focus you described.
- Background color: Very light grayish-teal (#F0F8FF), a desaturated tint of the primary, creates a calm and unobtrusive backdrop.
- Accent color: A muted, analogous green (#66A366), gives visual interest.
- Font pairing: 'Poppins' (sans-serif) for headlines, paired with 'PT Sans' (sans-serif) for body text, balances modernity with readability.
- Simple, outline-style icons to represent subjects and actions.
- Clean, card-based layout for subjects and attendance records.
- Subtle transitions for marking attendance and loading stats.
